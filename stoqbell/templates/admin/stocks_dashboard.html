Fundamentals data

Last synced: {{ fundamentals_last_synced_ist or 'not yet run' }}

Why is there no button here?

PE, EPS, ROCE, and every other fundamental come from scraping Screener.in one company at a time -- a slow, rate-sensitive process. It refreshes automatically in the background, a small batch each day, cycling through every eligible company roughly once every 15 days. This is deliberately not something you can click to run on demand: running it more often than that risks getting throttled or blocked by Screener.in for everyone. If you need to check when a specific company's fundamentals were last refreshed, see its company detail page.

Pick of the Day

Picks a single top-ranked golden-cross stock from the current watchlist/indicators/fundamentals that clears at least the bronze StoqBell Score bar, then emails everyone on the recipient list -- a stock already sent within the last 30 days is skipped in favor of the next-best one unless its pick has genuinely changed, so this rotates through the qualifying list instead of repeating the same stock every day. Can send nothing on a day when everything that qualifies is on cooldown or nothing clears the bar at all.

Announcements

One-time email to every active viewer: Nari Nakhre Stocks has been renamed StoqBell, with its own domain and its own sending address. This is meant to be sent ONCE -- re-running it emails everyone again, so only use this if the first send genuinely failed for most recipients.

Advanced: run individual sync steps

Super Sync above already runs all of these together, in order. Use these only if you need to re-run just one step on its own -- for example after fixing a Kite session, or to isolate which step is failing.

Data sync

Pulls the latest daily candle for every active watchlist symbol.

Matches Kite's own instrument list against our companies by name, so price sync can use Kite's real ID instead of guessing -- run this if "Sync now" reports symbols Kite has no quote for. Not a daily task.

Universe-wide scan

Pulls daily prices for all ~1,067 scrape-eligible companies (not just the watchlist) -- takes several minutes. Run this before "Calculate indicators (universe)" below.

Computes moving averages (5/21/50/200-day), RSI, and cross-over status for every company with universe-wide price data -- this is what powers "Golden cross, not yet qualified" on the watchlist page.

Watchlist shortlist

Re-evaluates every scrape-eligible company's latest fundamentals against the screening criteria and updates the watchlist accordingly. Also runs automatically each morning before market open.
